# 库坝知识库 Word 编写规范

本规范用于配合知识库条款级解析、检索增强和报告引用溯源。上传到知识库的 Word 建议按 5 类组织：

1. 极端天气与自然灾害事件识别规范
2. 人员安全与非法行为识别规范
3. 风险分级与告警判定规则
4. 联动设备调用规范
5. 应急处置措施与人员协同规范

每条可引用知识必须使用固定字段，系统会优先按 `条款编号` 切片，并把章节、段落、条款和来源类型写入 `KnowledgeChunk.metadata_json`。

## 条款模板

```text
条款编号：RISK-FLOOD-003
适用事件：洪水
适用场景：水位快速上涨、库岸冲刷、道路被淹或接近警戒区域
风险等级：高风险
触发条件：视频显示水流冲刷岸坡或水位快速上涨，并伴随降雨、水位或现场告警信息。
识别特征：水面流速明显增大，近岸区域被淹，岸坡或设施周边出现冲刷迹象。
研判依据：洪水期间水流冲刷可能导致岸坡失稳、设施损坏或人员通行风险。
联动设备：无人机、云台摄像头、广播
联动人员：值班人员、现场巡查人员、应急负责人
处置动作：加强视频复核和现场巡查，必要时调用无人机开展空中复核，并对危险区域人员进行广播提醒。
限制条件：强风、雷电、台风或能见度不足时，应暂停无人机起飞。
报告表达：当前水位上涨及水流冲刷迹象提示现场存在较高风险，建议加强巡查并做好应急处置准备。
引用关键词：洪水 水位上涨 岸坡冲刷 无人机 广播 巡查
```

## 编写要求

- Word 标题请使用“标题 1/标题 2/标题 3”样式，系统会生成 `section_path`。
- 每条知识必须包含 `条款编号`、`适用事件`、`适用场景`、`处置动作`、`报告表达`。
- 风险类条款必须包含 `风险等级` 和 `触发条件`。
- 设备联动类条款必须包含 `联动设备`、`限制条件`。
- 人员安全类条款必须包含 `联动人员` 和 `处置动作`。
- `报告表达` 应写成可直接放进报告的正式中文句子。
